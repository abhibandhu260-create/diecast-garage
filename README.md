# Diecast Collection Tracker

React + Vite app for a 1:64 diecast wishlist.

- Check a car to move it into the green Bought Cars panel at the top.
- Add a car and choose an existing category, or create a new category.
- Search by model or category, remove entries, and track collection progress.
- Saves automatically in browser localStorage.

## Run
```bash
npm install
npm run dev
```

The 11 category names come from your earlier checklist. The three already-owned cars are pre-checked: Dodge Challenger, Maruti Suzuki Swift and Porsche 911. The rest is a starter catalogue you can edit in the app.
